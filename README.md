# LabGear — Laboratory Equipment Reservation System

LabGear is a web-based laboratory equipment reservation and management system developed for the **IT 107 System Security Final Project**.

The system allows students and instructors to reserve laboratory equipment while laboratory technicians manage approvals, equipment issuance, returns, inventory, and maintenance.

## Features

- User Registration and Secure Login with Email OTP
- Password Recovery and Account Security
- Laboratory Equipment Reservations and Cancellation
- Equipment Approval, Issuance, and Returns
- Equipment Inventory Management
- Damage and Repair Tracking
- Admin User Management and Security Monitoring
- Activity Logs and Security Protections

## Technologies Used

- **Frontend:** React, JavaScript, Vite
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL
- **Security:** Email OTP, CAPTCHA, CSRF Protection, Password Hashing, Session Security
